# Ludy
A personal app to manage board game libraries.

## Start

Before starting the app locally, you should have a mongodb server running in your machine and an environment variable `DATA_BASE_URI` containing the uri of a database to use such as `mongodb://localhost:27017/ludy`.

To start the app in localhost, run the following command

```./mvnw spring-boot:run```

The app will be then available at

[http://localhost:8080/ludy](http://localhost:8080/ludy/)
